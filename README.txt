ZIA NATURAL SOAP COLLECTION - FLASK WEBSITE

1. Install Python.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   pip install -r requirements.txt
5. Run:
   python app.py
6. Open:
   http://127.0.0.1:5000

Files:
- app.py = complete website code
- static/poster.jpg = your uploaded poster
- requirements.txt = Flask dependency
- orders.json = created automatically after the first order

IMPORTANT:
- Change WHATSAPP_NUMBER and product prices in app.py when needed.
- The current version uses Cash on Delivery and WhatsApp ordering.
- Online UPI/card payment can be connected later.
